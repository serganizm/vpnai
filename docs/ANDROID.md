# Android 0.6.0

Android 7+ ARM64. Локальный Python backend и SSH работают внутри приложения.

Для установки откройте APK. Подпись опубликованной APK сохранена от предыдущей локальной сборки.

Сборка из исходников: JDK 17, Android SDK 35, Python 3.12. Из каталога android выполните `python3.12 prepare_payload.py ..`, затем `./gradlew assembleDebug`. Для собственного обновления используйте тот же ключ подписи; приватный ключ автора в исходники не входит.

Три раздела: Подключение, Установка, Управление. JSON/TXT-шаблон данных серверов доступен в меню «Файл». Данные доступа хранятся в памяти сеанса. Во время операций оставляйте приложение открытым.

Локальная проверка: запуск Python/Paramiko и криптографии, HTTP API с токеном, WebView, сохранение документа и перезапуск сеанса в Android 15 ARM64-эмуляторе. На реальных серверах при проверке релиза ничего не меняется.

Обычные «Проверить серверы» и «Проверить VPN» не изменяют настройки серверов; при неизвестных результатах отчёт неполный. Новая APK использует прежний ключ подписи. Для воспроизводимой собственной APK нужен собственный постоянный ключ; ключ автора не публикуется.

## DNS для VPN-клиентов

Общая настройка DNS доступна в «Управление → Маршрутизация»; при установке/обновлении включается отдельно. Google, Cloudflare или свои публичные IPv4. Применение требует подтверждения, перезапускает активный OpenVPN и требует переподключения клиентов. Чтение и проверка доступности не применяют настройки. «DNS клиента» отменяет выдачу DNS; «Не менять при установке» сохраняет действующие настройки. Подробности: [DNS.md](DNS.md).


## Лимиты подключений 0.6.0

Общий лимит — в установке и «Управление → Маршрутизация»; индивидуальный — в меню пользователя. Первый запуск функции на старой установке потребует переподключить устройства после подтверждения. Дальнейшее уменьшение лимита сохраняет текущие сеансы. Подробнее: [CONNECTION_LIMITS.md](CONNECTION_LIMITS.md).

При сборке Gradle автоматически обновляет payload.zip из текущих app, docs и android/ui; ручная упаковка больше не обязательна. Перед публикацией содержимое APK побайтово проверяется против исходников тега.
