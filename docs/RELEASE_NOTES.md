# VPNAI v0.1.15

Обновление интерфейса установщика:

- Убрана верхняя панель «Рабочее пространство / Установщик» и «Установка VPN».
- «Инструкция» и «Настройка» расположены у правого края на уровне номера шага.
  Удалена подпись «· VPNAI ·» рядом со ссылками.
- На каждом шаге слева находится светло-красная кнопка «Закрыть VPNAI».
  Справа — «Назад» и продолжение. Кнопки имеют одинаковые размеры и стоят
  в одной строке; текст не переносится. На обычном широком окне размер 220 × 46 px.
- Подпись о данных текущего сеанса перенесена в нижнюю часть страницы.
- Во всех выпадающих списках одинаковые стрелки с отступом 16 px от правого края.
- Инструкции и названия файлов сверены с текущим интерфейсом.

Установка VPN, маршрутизация, пользователи, парные архивы и обновление HTTPS
работают по прежней схеме. Этот релиз не содержит исправления тайм-аута клиента
или изменений серверных параметров OpenVPN.

Готовые приложения: Windows x64, Mac Apple Silicon и Linux x64.
Python и SSH-компонент включены. Исходники — отдельный архив.
Поддерживаются только парные резервные копии нового формата.
Публикация выполняется после тестов и проверки готовых сборок на трёх ОС.
Релиз предназначен для дальнейшего тестирования на реальных серверах.
