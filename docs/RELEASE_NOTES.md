# VPNAI v0.2.1

## Администрирование установленного VPN

- Отдельные режимы «Установка/Обновление» и «Администрирование».
- Подключение к паре серверов по SSH с проверкой отпечатков; пароль, приватный ключ или локальный ключ.
- Пользователи и активные подключения: IP клиента, VPN-адрес, время в сети и отдельный трафик каждой сессии.
- Создание и удаление пользователей, изменение комментариев и паролей, генерация пароля и локального QR-кода.
- Скачивание UDP/TCP-профилей и создание временных HTTPS-ссылок.
- Чтение и редактирование списков RU/RU-EU, обновление IPList.
- Реальная проверка GRE/IPsec с отображением задержки, независимые индикаторы подключения двух режимов.
- Сохранение данных подключения только в памяти текущего запуска, включая обновление страницы.
- SSH-алиасы из пользовательского и системного SSH-конфига macOS, Windows и Linux, включая Include. Команды Match/ProxyCommand не исполняются; неподдерживаемые варианты отмечаются в списке.

## Обновление текущей конфигурации

- Действие «Восстановить» переименовано в «Обновить/Восстановить».
- Вариант «Обновить текущую конфигурацию» загружает текущие режимы и списки, позволяет изменить маршрутизацию, способ входа, порт и ручные адреса.
- Обновляет компоненты и серверное меню, сохраняя существующих пользователей, сертификаты и действующие пароли. Новый пользователь создаётся только при отсутствии неудалённых пользователей.
- Перед записью создаются парные резервные копии. Проверка версии загруженной конфигурации предотвращает применение изменений поверх устаревших данных.
- Серверное меню получило отдельный пункт «Изменить комментарий».

При обновлении службы перезапускаются, текущие VPN-сессии прерываются. Если способ входа, адрес и порт не изменились, прежние профили остаются пригодны. При изменении способа входа или порта импортируйте новые профили. При включении парольного входа для пользователя без сохранённого действующего пароля генерируется новый пароль, включённый в архив профилей.

Готовые сборки: Windows x64, macOS Apple Silicon и Linux x64. Python и SSH-компоненты включены. Также доступен архив исходников и SHA256SUMS.txt. Публикация выполняется после успешных проверок на всех трёх ОС.
