# VPNAI 0.8.0

- SSH к зарубежному серверу (EU) можно вести **через российский (RU)**, если публичный SSH к EU закрыт. В разделе «Подключение» выберите «Через RU» и цель: публичный IP EU или GRE `10.78.0.2` после установки.
- Отпечаток EU в режиме «через RU» читается по каналу с RU; доверие по-прежнему подтверждается один раз в сеансе.
- В обзоре серверов EU показывает путь управления: «напрямую» или «через RU» / «через RU · GRE».
- Единый интерфейс: Android payload собирается из `app/static` (без отдельной копии логики). Запуск desktop и Android без изменений.
- Установка, проверка и администрирование используют тот же режим `eu_ssh` / `eu_target`.

Файлы: Android ARM64, macOS Apple Silicon, Linux x64, Windows x64, исходники, общий архив и SHA256SUMS.txt. Настройки рабочих серверов при подготовке релиза не меняются.
