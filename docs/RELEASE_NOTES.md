Первый предварительный выпуск локального установщика **VPNAI** для macOS, Linux и Windows.

### Что скачать

Скачайте **VPNAI.zip** в разделе Assets и полностью распакуйте архив. `SHA256SUMS.txt` содержит SHA-256 архива. Репозиторий приватный: для скачивания нужен доступ к нему в GitHub.

В архиве:

```text
VPNAI/
├── app/
├── docs/
├── macos.command
├── linux.sh
├── windows.bat
└── readme.txt
```

### Запуск

Нужен Python 3.9 или новее.

- macOS: `macos.command` или `bash macos.command`.
- Linux: `bash linux.sh`.
- Windows: `windows.bat`.

Браузер откроется автоматически. **Демонстрационный режим включён по умолчанию — серверы не нужны.** Подробная инструкция: `docs/readme.md`; гайд по настоящим серверам находится в `docs/SETUP.md` репозитория.

### В выпуске

- OpenVPN UDP/TCP на российском сервере и GRE/IPsec к зарубежному серверу.
- Три режима IPv4-маршрутизации, отдельные ручные списки RU и RU-EU.
- Вход по сертификату с паролем либо только по индивидуальному сертификату.
- SSH по паролю/ключу, команды копирования публичного ключа для трёх ОС.
- Автоматическая подготовка Python на серверах; обновление пакетов ОС — опция Да/Нет, по умолчанию Нет.
- Серверное меню `/root/menu.sh`, отчёты, скачивание профилей и демонстрация без VPS.

### Статус проверки

28 автоматических тестов проходят при сборке. Архив собирается из проверенных файлов по контрольным суммам; служебные файлы ОС и личные данные не включаются.

Это предварительная версия для тестирования. Полная SSH-установка именно этой веб-версии на чистой паре VPS ещё не проверена. IPv6 остаётся прямым; дополнительно проверьте VPN со своего устройства.
