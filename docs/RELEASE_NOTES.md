# VPNAI v0.1.3

- Готовый архив в Assets теперь называется **VPNAI-v0.1.3.zip**. В следующих выпусках номер берётся автоматически из тега релиза.
- Файл `SHA256SUMS.txt` содержит контрольную сумму и точное имя архива с версией.
- Инструкции скачивания обновлены под имена вида `VPNAI-vX.Y.Z.zip`.
- Внутри архива остаётся папка `VPNAI` с приложением, файлами запуска и документацией в `docs`.

Для запуска нужен Python 3.9+. Краткая инструкция — `readme.txt`. Для SSH на настоящие серверы установите компонент на локальном компьютере: `app/setup-ssh-windows.bat`, `app/setup-ssh-macos.command` или `app/setup-ssh-linux.sh`.

28 автоматических тестов выполняются при сборке. Полная установка этой веб-версии на чистой паре VPS и запуск на физических Windows/Linux требуют отдельной проверки.
