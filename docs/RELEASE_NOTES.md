# VPNAI v0.1.16

- Пояснения под заголовками всех четырёх шагов отображаются в одну строку
  и используют доступную ширину страницы. В узком окне длинное пояснение
  можно прокрутить горизонтально.
- На шаге маршрутов пояснение заменено на:
  «IPList загружается с сайта. RU-EU и RU списки пусты — добавьте нужные вам IP-адреса».
  Слово «сайта» открывает https://iplist.opencck.org/ru/ в новой вкладке.
- Обновлены инструкции и ссылки скачивания для этой версии.

Серверные настройки OpenVPN, маршрутизация и восстановление не изменялись.
Готовые сборки: Windows x64, Mac Apple Silicon и Linux x64.
Python и SSH-компонент включены. Исходники доступны отдельным архивом.
Публикация выполняется после проверок на трёх ОС.
