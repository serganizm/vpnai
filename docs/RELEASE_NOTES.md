# VPNAI v0.1.11 — повторная установка после удаления

Поддерживаются Windows x64, Linux x64 и Mac Apple Silicon.

## Исправлено

- Повторная установка принимает оставшийся nginx со стандартной конфигурацией после удаления своей установки на той же паре серверов.
- Проверяются сохранённая отметка удаления, владелец слушающего порта, синтаксис nginx и отсутствие дополнительных сайтов; чужие веб-службы не обходятся.
- Штатный сайт nginx не удаляется и сама служба ради освобождения порта не останавливается.
- Ожидание завершения IPsec при удалении ограничено 20 секундами вместо ожидания сетевых повторов около трёх минут.
- Сохранены проверки и закрытые архивы обоих серверов перед удалением.

Если прежняя установка уже удалена, запустите новую сборку и выберите
«Установить VPN». При действующей установке доступны восстановление и
установка заново.

## Что скачать

- **Windows:** VPNAI-v0.1.11-windows-x64.exe — запустите двойным щелчком.
- **macOS Apple Silicon:** VPNAI-v0.1.11-macos-arm64.zip.
- **Linux x64:** VPNAI-v0.1.11-linux-x64.tar.gz.

Для macOS/Linux распакуйте архив и запустите единственный исполняемый файл. Python, Paramiko, pip и setup-ssh на компьютере больше не требуются. Они включены в сборку; при запуске ничего не скачивается и системный Python не изменяется. Временная распаковка встроенных библиотек выполняется автоматически.

Интерфейс открывается в браузере. Сохранены автоматические SSH-отпечатки, подтверждение первого доверия и совместимость проверки со старой установкой. Инструкции встроены в приложение.

## Проверка и ограничения

95 регрессионных тестов (проверка shell-синтаксиса выполняется на Unix), сборка на Windows/Linux/macOS Apple Silicon и офлайн-тест каждого готового файла. Тест проверяет встроенный SSH, нативную криптографию, шаблоны, HTTP и демонстрацию без папки app и без подключения к VPS. Полная установка VPN на чистых VPS и физические клиентские устройства проверяются отдельно.

Сборки пока не имеют издательского сертификата Windows/Apple Developer ID; возможны предупреждения ОС. Поддерживаемые локальные ОС: Windows 10/11 x64, macOS 15+, Linux x64 glibc 2.35+. Windows/Linux ARM64 не включены.

VPNAI-source-v0.1.11.zip — необязательные исходники для разработчиков, для них сохраняются Python-скрипты запуска. SHA256SUMS.txt содержит контрольные суммы всех файлов.
