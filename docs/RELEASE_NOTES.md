# VPNAI v0.1.4

Исправления по результатам диагностики существующей пары серверов:

- Проверка поддерживает старую установку с состоянием версии 1: split-status.json не требуется для полного IPv4-туннеля.
- Для раздельного режима сохраняется строгая проверка файла статуса; отсутствие или повреждение не маскируется успехом.
- Режимы маршрутизации и авторизации считываются из конфигураций OpenVPN UDP/TCP. Сводка показывает настройки сервера, а не просто выбор формы.
- Проверка не меняет режим. Восстановление с другим режимом блокируется до записи конфигураций; существующие списки не заменяются полями формы.
- Каждая обязательная служба проверяется отдельно. Ошибки называют этап и сервер; тестовые выходы RU/NL имеют безопасные диагностические коды.
- Отказ SSH-авторизации показывает сервер и способ входа без раскрытия пароля. Получение отпечатков явно отделено от проверки пароля.
- Веб-проверка не перезаписывает отчёт на сервере; результат доступен для скачивания локально. Временные ресурсы функционального теста очищаются штатно.

40 автоматических тестов проходят при сборке, включая 12 регрессионных.
Новая версия не запускалась автоматически на действующих серверах; полная установка на чистой паре VPS и физические клиентские устройства требуют отдельной проверки.

Скачайте **VPNAI-v0.1.4.zip**, распакуйте в новую папку. На локальном компьютере запустите установщик SSH-компонента из app для своей ОС, затем обычный файл запуска. Для существующих серверов сначала выберите **Проверить VPN**. Подробности — docs/SETUP.md.
