# VPNAI 0.6.0

- В меню конфигураций пользователя первым показывается «QR-код и ссылка», затем «Скачать ZIP-архив» с подписью «Скачать конфигурацию на устройство». Одинаковый доступ из списка пользователей и списка конфигураций.
- QR-код и ссылка скачивают один выбранный файл .ovpn. UDP и TCP выбираются отдельно и имеют собственные ссылки. Показано оставшееся время.
- Срок — 10 минут с момента создания на сервере. При закрытии окна и повторном открытии в том же подключении возвращается прежняя действующая ссылка, без продления срока. После истечения создаётся новая. Изменившийся профиль, отключённый пользователь и удалённая ссылка проверяются повторно перед выдачей.
- Уже скачанный профиль продолжает работать после истечения ссылки, пока пользователь и сертификат действительны. Ссылка предоставляет доступ к приватному профилю: передавайте её только владельцу доступа. Новый сервис и перезапуск VPN для выдачи ссылки не требуются; используется существующий HTTPS-сервис VPNAI. Если HTTPS не настроен, приложение сообщает об этом.
- «Пароль и комментарий» сохраняет редактирование, генерацию и показ пароля; QR-код с паролем убран.
- В Android действия «Управлять» и «Получить файлы» выровнены вправо.
- Сохранены исправление кавычек обработчиков OpenVPN и проверка конфигураций до перезапуска из предыдущего выпуска. Упаковка APK автоматически строится из актуальных исходников и побайтово проверяется перед публикацией. Тесты изолированы от системных каталогов ОС; Linux CI проверяет настоящий парсер OpenVPN.

Файлы: Android ARM64, macOS Apple Silicon, Linux x64, Windows x64, исходники, общий архив и SHA256SUMS.txt. Настройки рабочих серверов при подготовке релиза не меняются.
