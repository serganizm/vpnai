# VPNAI v0.1.10 — исправление удаления

Поддерживаются Windows x64, Linux x64 и Mac Apple Silicon.

## Исправлено

- Удаление на зарубежном сервере работает без `ipset` и `nginx`.
- Применяется текущий код отката из приложения вместо старого серверного скрипта.
- Готовность и резервные копии обоих серверов проверяются до остановки служб.
- Повторный запуск продолжает частично завершённое удаление.
- В отчёте сохраняются результаты по каждому серверу и пути закрытых архивов.
- Чужие активные IPsec-подключения не приводят к остановке общей службы.

Для повторения операции закройте старую версию, запустите новую и выберите
«Удалить установку», затем подтвердите словом **УДАЛИТЬ**.

## Что скачать

- **Windows:** VPNAI-v0.1.10-windows-x64.exe — запустите двойным щелчком.
- **macOS Apple Silicon:** VPNAI-v0.1.10-macos-arm64.zip.
- **Linux x64:** VPNAI-v0.1.10-linux-x64.tar.gz.

Для macOS/Linux распакуйте архив и запустите единственный исполняемый файл. Python, Paramiko, pip и setup-ssh на компьютере больше не требуются. Они включены в сборку; при запуске ничего не скачивается и системный Python не изменяется. Временная распаковка встроенных библиотек выполняется автоматически.

Интерфейс открывается в браузере. Сохранены автоматические SSH-отпечатки, подтверждение первого доверия и совместимость проверки со старой установкой. Инструкции встроены в приложение.

## Проверка и ограничения

81 регрессионный тест (проверка shell-синтаксиса выполняется на Unix), сборка на Windows/Linux/macOS Apple Silicon и офлайн-тест каждого готового файла. Тест проверяет встроенный SSH, нативную криптографию, шаблоны, HTTP и демонстрацию без папки app и без подключения к VPS. Полная установка VPN на чистых VPS и физические клиентские устройства проверяются отдельно.

Сборки пока не имеют издательского сертификата Windows/Apple Developer ID; возможны предупреждения ОС. Поддерживаемые локальные ОС: Windows 10/11 x64, macOS 15+, Linux x64 glibc 2.35+. Windows/Linux ARM64 не включены.

VPNAI-source-v0.1.10.zip — необязательные исходники для разработчиков, для них сохраняются Python-скрипты запуска. SHA256SUMS.txt содержит контрольные суммы всех файлов.
