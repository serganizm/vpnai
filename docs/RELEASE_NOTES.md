# VPNAI 0.5.1

Исправлена ошибка первого включения лимитов в 0.5.0: OpenVPN отклонял команду client-connect из-за отсутствующих кавычек. Исправление применяется как к существующим установкам, так и к новой установке и всем режимам маршрутизации.

Перед изменением действующих конфигураций приложение проверяет подготовленные файлы настоящим парсером OpenVPN в безопасном режиме --show-ciphers. Ошибка проверки не перезапускает службы. При неудаче сообщение показывает исходную причину, сохраняя резервную копию и откат.

Рабочие VPN-серверы при подготовке выпуска не изменялись. После запуска новой версии повторите сохранение лимита; первое успешное включение потребует переподключения клиентов. Пользователи, сертификаты, DNS и маршруты этой операцией не заменяются. После первого включения изменения лимитов не перезапускают OpenVPN.

Файлы: Android ARM64, macOS Apple Silicon, Linux x64, Windows x64, исходники, общий архив и контрольные суммы. [Лимиты подключений](CONNECTION_LIMITS.md).
