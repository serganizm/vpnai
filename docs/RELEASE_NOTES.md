# VPNAI v0.1.5

- SSH-ключи автоматически получаются перед запуском операции; ручная кнопка и галочка удалены.
- Для нового сервера показывается одно подтверждение первого доверия с адресом, портом и SHA-256-отпечатком. При отмене пароль не передаётся серверу.
- Подтверждённые отпечатки сохраняются локально в ~/.vpnai/ssh-hosts.json без паролей и приватных ключей. Повторные подключения не требуют подтверждения, если ключ совпадает.
- Изменившийся ключ блокирует запуск. Подмена ключа между получением и подключением также отклоняется.
- Серверная часть не позволяет обойти доверие прямым запросом запуска операции. Одноразовое подтверждение действует 5 минут.
- Ошибки получения ключа называют сервер и порт, без раскрытия секретов.
- Инструкции обновлены; добавлено docs/SSH_TRUST.md. Сохранены исправления старой установки из v0.1.4.

58 автоматических тестов проходят при сборке; синтаксис JavaScript проверен локально. Новая версия не запускалась на действующих серверах автоматически.

Скачайте **VPNAI-v0.1.5.zip**, распакуйте в новую папку, установите SSH-компонент для своей ОС на локальном компьютере и запустите приложение. Для существующего VPN сначала выберите **Проверить VPN**. При запуске подтвердите доверие новым серверам.
