# VPNAI 0.5.0

- Серверный лимит одновременных подключений каждого пользователя, общий для UDP/TCP. Число 1–1000, без ограничений или индивидуальное наследование серверного значения. Работает с паролем и только по сертификату, независимо от запущенного приложения.
- Значение по умолчанию выбирается при установке/обновлении и в «Управление → Маршрутизация». Индивидуальное значение — «Управлять → Одновременные подключения». Бейдж показывает максимум, ∞ — безлимит, «—» — значение ещё не прочитано.
- При уменьшении лимита существующие подключения сохраняются; новые отклоняются до освобождения места. Первое включение на старой установке требует подтверждения перезапуска активных OpenVPN-служб и переподключения устройств. Дальнейшие изменения лимитов служб не перезапускают. Новые клиентские конфиги для изменения лимита не нужны.
- Атомарный общий учёт подключений с блокировкой; обработка отключения и перезапуска процесса, защита от повторного использования старого индивидуального лимита после перевыпуска сертификата. Состояние хранится на сервере, не в приложении. Повреждённая политика не разрешает обход ограничения.
- Перенесён согласованный интерфейс в web и Android: компактные центрированные карточки, короткая запись памяти, отдельные плашки ресурсов, выравнивание статусов серверов, бейджи лимита и одинаковые пункты меню с иконками. Мобильные вкладки подняты над линией; «Отключиться» светло-красная.
- Успешное подключение показывает «Подключено» светло-зелёным по центру; ошибка — подробный светло-красный текст.

[Лимиты подключений](CONNECTION_LIMITS.md), [обновление существующих установок](LOCAL_LEGACY.md), [DNS](DNS.md).

Файлы: Android 7+ ARM64 (APK), macOS Apple Silicon (ZIP), Linux x64 (TAR.GZ), Windows x64 (EXE), исходники, общий архив и SHA256SUMS.txt. В приложения входят Python и SSH. Сохранена прежняя Android debug-подпись; Mac-сборка не нотарифицирована Apple. Подготовка релиза не применяет настройки к рабочим VPN-серверам.
