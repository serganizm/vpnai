# VPNAI v0.1.12 — автоматическое продление HTTPS через NL

Поддерживаются Windows x64, Linux x64 и Mac Apple Silicon.

## Исправлено

- Пригодный сертификат используется повторно: проверяются срок не менее суток, IP, доверенная цепочка, соответствие ключа и конфигурация продления Certbot.
- Выпуск и продление обращаются к Let’s Encrypt через ограниченный CONNECT-канал по GRE/IPsec на NL; прямое соединение используется как запасной вариант.
- Приватный ключ и учётная запись Certbot остаются на RU; TLS проверяется до сервера Let’s Encrypt.
- Автопроверка продления выполняется каждый час и после перезагрузки. Новый сертификат запрашивается только когда это требуется Certbot.
- При успехе nginx перечитывает сертификат; ошибка обновления сохраняет сертификат и не останавливает VPN.
- Добавлены статусы попыток и понятные ошибки сети, HTTP-проверки и ограничений CA.
- Восстановление незавершённой установки после автоматического отката использует сохранённые параметры, пользователей и ключи.

После предыдущего сбоя HTTPS выберите «Восстановить установку» с той же
парой серверов и прежними режимами. Новые службы и таймер устанавливаются
при запуске новой версии на серверах; скачивание файла само их не включает.

## Что скачать

- **Windows:** VPNAI-v0.1.12-windows-x64.exe — запустите двойным щелчком.
- **macOS Apple Silicon:** VPNAI-v0.1.12-macos-arm64.zip.
- **Linux x64:** VPNAI-v0.1.12-linux-x64.tar.gz.

Для macOS/Linux распакуйте архив и запустите единственный исполняемый файл. Python, Paramiko, pip и setup-ssh на компьютере больше не требуются. Они включены в сборку; при запуске ничего не скачивается и системный Python не изменяется. Временная распаковка встроенных библиотек выполняется автоматически.

Интерфейс открывается в браузере. Сохранены автоматические SSH-отпечатки, подтверждение первого доверия и совместимость проверки со старой установкой. Инструкции встроены в приложение.

## Проверка и ограничения

122 регрессионных теста (проверка shell-синтаксиса выполняется на Unix), сборка на Windows/Linux/macOS Apple Silicon и офлайн-тест каждого готового файла. Тест проверяет встроенный SSH, нативную криптографию, шаблоны, HTTP и демонстрацию без папки app и без подключения к VPS. Полная установка VPN на чистых VPS и физические клиентские устройства проверяются отдельно.

Сборки пока не имеют издательского сертификата Windows/Apple Developer ID; возможны предупреждения ОС. Поддерживаемые локальные ОС: Windows 10/11 x64, macOS 15+, Linux x64 glibc 2.35+. Windows/Linux ARM64 не включены.

VPNAI-source-v0.1.12.zip — необязательные исходники для разработчиков, для них сохраняются Python-скрипты запуска. SHA256SUMS.txt содержит контрольные суммы всех файлов.
