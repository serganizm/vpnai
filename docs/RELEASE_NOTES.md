# VPNAI v0.1.14

- Восстановление из парного архива: выбор копии на российском сервере,
  автоматический подбор зарубежной по общим имени, ID и конфигурации туннеля.
  Поддерживается только новый формат. Перед заменой создаётся защитная пара.
- Проверка архивов до замены данных: содержимое, пути, целостность и принадлежность
  выбранной паре серверов. Служебные программы разворачиваются из установщика.
- IP, пароли, приватные ключи и SSH-доверие сохраняются между операциями только
  в памяти запуска. После выхода из приложения новый сеанс начинается заново.
- Только работа с серверами, без демонстрационного режима.
- Порядок действий: установка / установка заново / восстановление;
  проверка VPN / проверка серверов / удаление.
- Подтверждение удаления и замены данных флажком с описанием последствий.
- Логин из формы применяется при восстановлении: новый пользователь создаётся,
  активный существующий сохраняет пароль. Проверяются UDP/TCP-профили.
- Универсальные имена скачиваемых архивов: `openvpn-ЛОГИН.zip`, `openvpn-all.zip`.
- Обновлён интерфейс: круглый логотип, ссылка на репозиторий GitHub, документация
  справа от вводного текста каждого шага и под ним на узком экране.
- Ссылки на инструкции сверены с файлами: «Инструкция» открывает
  `docs/readme.md`, «Настройка» — `docs/SETUP.md`, краткий запуск — `readme.txt`.

Готовые приложения: Windows x64, Mac Apple Silicon и Linux x64.
Python и SSH-компонент включены. Исходники распространяются отдельным архивом.
Сборки проходят автоматические проверки на соответствующих ОС перед публикацией.
Релиз предназначен для дальнейшего тестирования установки и восстановления
на реальных серверах; тесты с подменой SSH не заменяют такую проверку.
