# VPNAI v0.1.2

- В `readme.txt` и подробные инструкции добавлена установка SSH-компонента на компьютере: закрыть приложение, запустить установщик своей ОС из `app`, дождаться «Готово» и снова открыть приложение.
- Установщики переименованы: `setup-ssh-windows.bat`, `setup-ssh-macos.command`, `setup-ssh-linux.sh`.
- Подсказки и сообщения об отсутствующем SSH-компоненте показывают новые имена и порядок действий.
- Для скачивания Paramiko нужен интернет; демонстрация работает без SSH-компонента.

Скачайте **VPNAI.zip** из Assets и распакуйте целиком. Краткий запуск — `readme.txt`, подробная инструкция — `docs/readme.md`. Python 3.9+ нужен на компьютере.

28 автоматических тестов проверяются при сборке. Установка веб-версии на чистой паре VPS и запуск на физических Windows/Linux ещё требуют отдельной проверки.
