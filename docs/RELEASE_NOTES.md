# VPNAI 0.4.1

- Исправлено зависание блокировки после завершения операции. Штатное завершение, ошибка и отмена закрывают служебный SSH-сеанс с подтверждением. При потере связи неработающая аренда истекает через 45 секунд после последнего сигнала. Работающая серверная команда сохраняет защиту от параллельного запуска до своего завершения.
- «Обновить/Восстановить» автоматически читает текущие параметры, DNS и ручные списки с сервера; переход к маршрутам перечитывает их, сохраняя несохранённые правки. Открытие «Управления» обновляет состояние серверов, пользователей, маршруты и DNS.
- Добавлено чтение установок без state.json/owned.json. Для них доступна отдельная смена «сертификат + пароль / только сертификат» и DNS без переустановки VPN, пересоздания пользователей или сертификатов. Недостающие профили не создаются автоматически. Порт, компоненты и режим маршрутизации сохраняются; ручные маршруты редактируются в «Управлении».
- DNS доступен также при обновлении. Изменение включается в операцию только явным выбором; частичная ошибка смены входа/DNS отображается отдельно. Ошибка чтения не подменяется значением «DNS клиента».
- Android получил те же изменения с сохранением мобильного интерфейса. Поведение сохранения паролей не менялось.

После смены способа входа скачайте обновлённые профили и импортируйте их на устройства. Сертификаты и сохранённые пароли пользователей сохраняются. Обычное чтение не применяет настройки. [Особенности обновления старых установок и блокировок](LOCAL_LEGACY.md), [DNS](DNS.md).

Файлы: Android 7+ ARM64 (APK), macOS Apple Silicon (ZIP), Linux x64 (TAR.GZ), Windows x64 (EXE), исходники, общий архив четырёх приложений и SHA256SUMS.txt. Готовые приложения содержат Python и SSH. Сохранена прежняя Android debug-подпись; Mac-сборка не нотарифицирована Apple. Для использования исправления завершите предыдущую копию приложения и запустите новую.
