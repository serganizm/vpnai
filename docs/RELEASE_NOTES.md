# VPNAI 0.3.2

- Исправлена диагностика работающего VPN без state.json/owned.json. Отсутствие файлов установщика теперь предупреждение, не признак отсутствия VPN.
- «Проверить серверы» больше не запускает установочный preflight и не отклоняет существующую подсеть 10.77.0.0/24 как конфликт новой установки.
- «Проверить VPN» читает реальные конфигурации, службы, порты, пересылку IPv4, маршруты, существующий GRE и IPsec SA. Она не создаёт временные сети, файлы или lock-файл установщика и не перезапускает службы.
- Результат каждого пункта сохраняется в отчёте: успех, замечание или неизвестно. Недоступный ping/swanctl не выдаётся за доказанный отказ VPN. Выбранные в форме режимы отделены от фактически прочитанных.
- HTTPS, сквозные выходы трафика и клиент OpenVPN не входят в обычную диагностику. Глубокая проверка после установки сохранена.
- Перепроверены инструкции, описание интерфейса, завершение приложения, импорт файла серверов, Android и границы проверок.

Файлы: Android ARM64, macOS Apple Silicon, Linux x64, Windows x64, исходники desktop/Android, общий архив четырёх приложений и SHA256SUMS.txt. Desktop проверяется на каждой ОС; Android — в Android 15 ARM64-эмуляторе. Совместимость со всеми физическими устройствами не подтверждается.

Для обычного запуска Python устанавливать не нужно. APK сохраняет прежнюю debug-подпись; Mac-приложение не нотарифицировано Apple. Серверная установка и управление по-прежнему требуют совместимых компонентов; успешная диагностика не означает разрешения обновлять или удалять нераспознанную установку.

При подготовке релиза VPS не изменялись. Исправления воспроизведены на изолированных тестах; повторная проверка пользовательской пары выполняется пользователем.
