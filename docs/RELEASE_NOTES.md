# VPNAI 0.3.3

- Настройка DNS для всех VPN-клиентов: Google, Cloudflare или один/два своих публичных IPv4. Доступна в «Управление → Маршрутизация» и параметрах установки/обновления.
- Выбранные DNS передаются профилям UDP/TCP; запросы к ним направляются через GRE/IPsec на зарубежный сервер. DNS самой ОС серверов и списки RU/EU не меняются. Клиент должен принимать настройки сервера; собственный DoH может их обходить.
- «DNS клиента» убирает выдачу DNS и отдельные DNS-маршруты. «Не менять при установке» сохраняет действующие настройки. Старые ручные адреса автоматически не возвращаются.
- Перед применением проверяется доступность DNS по UDP/TCP с EU, создаётся закрытая резервная копия. Применение требует подтверждения и перезапускает активные службы OpenVPN — клиенты должны переподключиться.
- Исправлены совместимость с пустой таблицей IPsec 220, чтение подсетей Linux src/srclen, откат после ошибки службы и повторное применение. Остатки незавершённой операции обрабатываются только при совпадении файлов с резервной копией и точном распознавании правил.
- Сообщение об ошибке остаётся видимым после чтения настроек; показывается предупреждение об оставшихся правилах.
- При обновлении сохраняются пользователи и уже настроенные DNS; включение DNS не требует создавать нового пользователя.

Готовые приложения: Android 7+ ARM64 (APK), macOS Apple Silicon (ZIP), Linux x64 (TAR.GZ), Windows x64 (EXE). Также доступны исходники, общий архив четырёх приложений и SHA256SUMS.txt. Python и SSH входят в готовые приложения. APK сохраняет прежнюю debug-подпись; Mac-приложение не нотарифицировано Apple.

Подробная инструкция: docs/DNS.md. Google DNS применены пользователем на рабочей паре серверов и подтверждены чтением; пользователь подтвердил запуск профиля на Android TV. Подготовка релиза не применяет настройки к VPS. Автоматические проверки используют подмену SSH и временные каталоги; работа на всех моделях телевизоров не гарантируется.
