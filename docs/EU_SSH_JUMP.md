# SSH к EU через RU — VPNAI 0.8.0

Если с вашего IP порт SSH зарубежного сервера недоступен, включите в «Подключение» режим **Через RU**.

## Режимы

| Режим | Когда использовать |
|---|---|
| Напрямую | EU:SSH открыт с устройства, где запущен VPNAI |
| Через RU → публичный IP EU | EU снаружи закрыт, но с RU до `EU:port` есть доступ |
| Через RU → GRE `10.78.0.2` | После установки, когда GRE/IPsec между RU и EU работает, а публичный SSH EU закрыт даже с RU |

## Ограничения

- Первая установка на EU всё равно требует, чтобы с RU (или напрямую) был доступен SSH EU. Если EU полностью закрыт до появления GRE, откройте SSH временно или используйте консоль провайдера.
- Без доступного RU режим «через RU» невозможен.
- Алиасы `ProxyJump` / `ProxyCommand` из пользовательского `~/.ssh/config` по-прежнему не подставляются: jump выполняет само приложение.

## Интерфейс

- Сегмент на форме подключения: «Напрямую» / «Через RU».
- При «Через RU» — выбор цели: публичный IP или GRE.
- На карточке EU в управлении — метка пути.
