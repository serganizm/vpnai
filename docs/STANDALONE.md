# Готовые приложения 0.8.0

| Платформа | Файл |
|---|---|
| Android 7+ ARM64 | VPNAI-v0.8.0-android-arm64.apk |
| macOS Apple Silicon | VPNAI-v0.8.0-macos-arm64.zip |
| Linux x64 | VPNAI-v0.8.0-linux-x64.tar.gz |
| Windows x64 | VPNAI-v0.8.0-windows-x64.exe |
| Исходники desktop и Android | VPNAI-source-v0.8.0.zip |
| Четыре готовых приложения вместе | VPNAI-v0.8.0-all-platforms.zip |

Распакуйте ZIP/TAR.GZ на Mac/Linux и запустите исполняемый файл. На Windows откройте EXE. Android: откройте APK и разрешите установку из выбранного источника. Готовые приложения содержат Python, SSH-библиотеки и интерфейс; отдельная установка зависимостей не нужна. Контрольные суммы опубликованы в SHA256SUMS.txt.

Desktop открывает браузер по адресу 127.0.0.1 со случайным токеном сеанса. Окно запуска должно работать всё время использования. Закрытие вкладки не завершает процесс. Для остановки после завершения операции нажмите Ctrl+C в окне запуска. Android использует встроенный WebView и службу с уведомлением; сворачивание не завершает сеанс. Системная остановка процесса очищает данные.

Основные вкладки: «Подключение», «Установка», «Управление». Пункты раздела на desktop слева, на телефоне внизу. В установке три пункта: настройки VPN, маршруты, запуск. Ссылки «Файл», «Инструкция», «Настройка» находятся над содержимым. «Назад» имеет фиксированную ширину 130 CSS px, продолжение занимает остальную ширину; стрелок и кнопки закрытия нет.

macOS-приложение не нотарифицировано; Windows может показывать предупреждение неизвестного издателя. Android использует прежнюю debug-подпись. Эти сборки не являются дистрибутивами Google Play/App Store.
