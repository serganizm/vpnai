# Готовое приложение

Поддерживаются Windows 10/11 x64, Mac Apple Silicon и Linux x64.
Распакуйте архив для macOS/Linux и запустите исполняемый файл; на Windows
откройте .exe. Откроется локальная страница в браузере.

Python, SSH-библиотеки и интерфейс включены в готовый файл. При запуске
они не скачиваются и не устанавливаются в системный Python. Служебная
распаковка выполняется во временную папку автоматически.

Приложение работает с двумя указанными серверами. IP, пароли и SSH-доверие
доступны только в памяти текущего процесса. Для выхода используйте
«Закрыть VPNAI». Закрытие вкладки само по себе не завершает приложение.

Сборка без издательской подписи может вызывать стандартное предупреждение ОС.
Документы открываются ссылками «Инструкция» и «Настройка» на одной строке с номером шага, у правого края.

Кнопка «Закрыть VPNAI» находится слева на каждом шаге. Справа расположены
«Назад» (начиная со второго шага) и кнопка продолжения. Все кнопки одинакового
размера; «Назад» и продолжение имеют фиолетовый фон, закрытие — светло-красный.

Кнопки навигации выровнены по одной линии. На широком окне их размер
220 × 46 px. В узком окне панель сохраняет одну строку; при нехватке места
её можно прокрутить горизонтально.
