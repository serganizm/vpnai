# Самостоятельные сборки VPNAI

Готовая сборка содержит Python, Paramiko, криптографические библиотеки, интерфейс и серверные шаблоны. На компьютер пользователя ничего не скачивается через pip, системный Python не изменяется. При запуске встроенные файлы автоматически распаковываются во временный каталог и удаляются после штатного завершения. Это техническая часть запуска одного файла, а не отдельная установка.

## Выбор файла

- Windows 10/11 x64: `VPNAI-v0.1.6-windows-x64.exe` — запустите двойным щелчком.
- macOS 15+ Apple Silicon: `VPNAI-v0.1.6-macos-arm64.zip`.
- macOS 15+ Intel: `VPNAI-v0.1.6-macos-x64.zip`.
- Linux x64 с glibc 2.35+ (например Ubuntu 22.04+): `VPNAI-v0.1.6-linux-x64.tar.gz`.

На macOS/Linux распакуйте архив: внутри один исполняемый файл. Архив нужен для сохранения права исполнения. Запустите этот файл; на Linux способ открытия зависит от файлового менеджера. При необходимости разрешите исполнение в свойствах файла. Поддержка более старых ОС и Windows/Linux ARM64 в этом выпуске не заявлена.

Самостоятельный файл открывает локальный веб-интерфейс в установленном браузере. Для демонстрации и встроенного самотеста интернет не нужен. Для работы с VPS интернет необходим. Программа не устанавливает фоновую службу на локальный компьютер.

## Работа

Введите данные серверов и запустите нужное действие. Подтверждение первого SSH-доверия сохранено; дальнейшая проверка ключей автоматическая. Для действующего VPN сначала используйте «Проверить VPN». Не закрывайте окно программы до завершения операции. Ctrl+C запрашивает штатную остановку. Закрытие вкладки не останавливает приложение.

## Подпись и ограничения

Сборки пока не имеют издательского сертификата Windows или Apple Developer ID/notarization. ОС/антивирус может запросить подтверждение либо заблокировать запуск. Это не означает, что для них нужен Python. Не утверждается, что все системные предупреждения устранены.

## Проверки сборки

Каждая платформа собирается на соответствующем GitHub runner с Python 3.12 и PyInstaller 6.22.3. На runner устанавливаются сборочные зависимости; пользователю они отдельно не передаются.

Перед публикацией выполняются регрессионные тесты, самотест нативной криптографии и запуск готового файла из отдельного каталога без папки app. Проверяются встроенный SSH, целостность шаблонов, локальный HTTP-интерфейс, встроенная инструкция и демонстрационный ZIP без подключения к VPS. Это не заменяет проверку на физическом устройстве и установку VPN на реальной паре серверов.

Рядом публикуется SHA256SUMS.txt для всех файлов. Исходники доступны отдельно в VPNAI-source-v0.1.6.zip; инструкции Python/setup-ssh относятся только к исходной версии.
