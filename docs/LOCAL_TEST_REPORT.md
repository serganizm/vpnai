# Дополнительные проверки обновления и блокировки — 0.5.0

297 регрессионных тестов: чтение без метаданных, сохранение пользователей, ключей, DNS и списков при смене входа в обе стороны, контроль версии, отказ для другой пары серверов, точный откат при ошибке, сохранение неактивной TCP-службы и отдельный путь без переустановки компонентов.

Браузер с подменённым API: автоматическое чтение при выборе обновления и входе в маршруты, отображение 14 записей RU, сохранение выбранного входа и изменений списков, отмена не запускает операцию. Настоящий сервер проверен только чтением; смена авторизации на нём во время разработки не запускалась.

Проверены выбор DNS в обновлении, проверка доступности до смены входа, применение с новым снимком DNS после смены входа, сохранение прежнего DNS, явный выбор «DNS клиента» и частичная ошибка второго этапа. В браузере проверено включение Google DNS в сводку обновления, без реальных серверных операций.

Дополнительно проверены общий ответ конфигурации с текущим DNS и явная ошибка чтения DNS. Браузерная проверка: DNS Google автоматически выбран при обновлении без перехода в управление; открытие управления читает состояние, списки и DNS; повторное открытие не сбрасывает выбранный Cloudflare. Проверка реального сервера выполнена только чтением: 4 пользователя, 14 записей RU, текущие Google DNS 8.8.8.8 и 8.8.4.4 получены одним загрузчиком.


Исправлена зависающая SSH-блокировка. Проверены штатное освобождение и повторное закрытие, ошибка команды, EOF, пропущенные сигналы, сохранение аренды сигналами, защита действующей команды после окончания аренды, отказ постороннему токену, передача входных данных и отключение транспорта. На RU и EU выполнены отдельные временные проверки успешной команды, ошибки и окончания аренды при открытом молчащем канале; во всех случаях тестовая блокировка освобождена, временные файлы убраны. Настройки и службы VPN при этих проверках не менялись.
