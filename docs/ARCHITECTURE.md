# Структура

## Локальное приложение

- `app/app.py`: локальный HTTP API, запуск, завершение и память текущего сеанса.
- `app/backend.py`: проверка ввода и управление операциями SSH.
- `app/diagnostics.py`: не изменяющая серверы диагностика check/verify, не зависящая от файлов принадлежности установки.
- `android/`: Android-оболочка, Python runtime, сборка payload и отдельный мобильный интерфейс в android/ui/.
- `app/backups.py`: каталог, проверка парных архивов и восстановление данных.
- `app/removal.py`: резервное копирование и удаление компонентов своей установки.
- `app/ssh_trust.py`: проверка ключей серверов; приложение использует временное доверие в памяти.
- `app/core/engine.py`: развёртывание и проверка компонентов на серверах.
- `app/core/payload/`: серверные файлы с подставляемыми параметрами.
- `app/static/`: интерфейс без внешних ресурсов.
- `docs/`: инструкции. `readme.txt`: краткий запуск.

## Российский сервер

| Путь | Назначение |
|---|---|
| `/root/menu.sh` | Главное меню управления |
| `/usr/local/libexec/ovpn-menu.py` | Логика меню |
| `/usr/local/sbin/ovpn-user` | Учётные записи и профили |
| `/etc/openvpn/server/` | Конфигурации UDP/TCP, пользователи, PKI |
| `/root/ovpn-profiles/` | Профили и файлы доступа |
| `/root/ovpn-downloads/` | Подготовленные ZIP-архивы |
| `/etc/ovpn-routing/` | Источник IPList и свои маршруты |
| `/var/lib/ovpn-routing/` | Рабочее состояние маршрутов |
| `/var/lib/ovpn-links/` | Временные ссылки |
| `/var/lib/ovpn-cert/status.json` | Результат проверки сертификата |
| `/etc/letsencrypt/` | Сертификат, приватный ключ и конфигурация продления |
| `/var/lib/ovpn-installer/` | Состояние установки и сведения о созданных файлах |

## Зарубежный сервер

Защищённый GRE/IPsec, правила выхода в интернет и ограниченная служба
`ovpn-acme-proxy`. Учётные записи пользователей OpenVPN и их приватные
профили находятся на российском сервере.

Архив пользователя называется `openvpn-ЛОГИН.zip`, общий — `openvpn-all.zip`.
Секреты не включаются в автоматические локальные журналы приложения.

Парные копии хранятся в `/root/ovpn-backup-ДАТА-ВРЕМЯ-ID.tar.gz` на обоих
серверах под одним именем. Манифест содержит общий ID, роль и адреса пары.
Старый формат не поддерживается. Служебные программы при восстановлении
разворачиваются из текущего установщика и не исполняются из архива.
