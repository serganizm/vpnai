# SSH-доверие

Отпечатки автоматически запрашиваются перед операцией. До передачи пароля
приложение просит подтвердить доверие впервые увиденным серверам. По возможности
сверьте отпечатки через консоль хостинга.

Подтверждение хранится только в памяти текущего запуска. Повторные операции
с той же парой не требуют повторного ввода паролей или подтверждения тех же
ключей. При изменении ключа в этом запуске соединение блокируется.

При закрытии приложения IP, пароли, приватные ключи и SSH-доверие очищаются
из памяти. Новый запуск требует ввода данных и подтверждения доверия заново.
Локальный файл базы доверия приложение не создаёт.

При смене ключа сервера проверьте причину через консоль провайдера. Автоматическая
подмена ключа внутри работающего сеанса запрещена.
