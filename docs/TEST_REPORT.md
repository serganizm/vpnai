# Проверки 0.3.3

252 регрессионных теста: валидация, SSH-доверие, диагностика, работа с пользователями и конфигурациями, DNS-транзакции, точный откат, повторное применение, Linux src/srclen, совместимость с пустой таблицей IPsec 220 и обработка подтверждённых остатков неудачной операции. Локально пройдены; GitHub Actions повторяет их на Windows, Linux и macOS.

Проверка интерфейса с подменой ответов: чтение DNS, проверка доступности, отмена и подтверждение применения, сохранение ошибки после чтения, включение DNS в установку. Android дополнительно проверяется в ARM64-эмуляторе: Python/SSH/криптография, DNS-модуль, локальный HTTP, WebView, экспорт документа и новый сеанс. Desktop проходит автономный запуск без установленного Python и без соседних исходников.

На рабочей паре серверов DNS применены самим пользователем; чтение подтвердило Google DNS, отдельные правила через EU и передачу DNS профилю tv2. Пользователь подтвердил запуск VPN-профиля на телевизоре. Во время сборки релиза никаких настроек VPS автоматически не применяется. Проверки не подтверждают работу на каждом физическом устройстве или всех сетях.
