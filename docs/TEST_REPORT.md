# Проверки — 29.10.2026

Пройдены **60 автоматических тестов**:

- проверка и нормализация IPv4/CIDR, пустые списки по умолчанию;
- валидация серверов, логина, порта и подтверждения удаления;
- все 6 сочетаний маршрутизации и авторизации, синтаксис Python-шаблонов;
- отдельный режим выхода всех IPv4 через зарубежный сервер;
- демонстрация успешной операции, ошибки, остановки и проверки;
- отсутствие сетевых соединений в демонстрации;
- проверка токена, Origin и Host локального API;
- запрет скачивания файлов по произвольному пути;
- отсутствие SSH-паролей в состоянии и отчёте;
- демонстрационный ZIP без действующих ключей/профилей и срок его доступности;
- полный путь оркестрации установки с подменой SSH-серверов: пустые ручные списки и сохранение конечного состояния;
- отказ до выполнения команд при несовпадении SSH-отпечатка.

В браузере проверены четыре шага интерфейса, пустые списки и завершение демонстрации. Повторное открытие вкладки возвращает к результату текущей операции, пока процесс приложения работает.

В пакет не включены личные списки прежних проектов, виртуальная среда Python, служебные файлы файлового менеджера и кэши. Интерфейс не загружает внешние шрифты или библиотеки.

Не проверено: полная SSH-установка веб-версии на чистой паре VPS; запуск на физических Windows/Linux; подключение OpenVPN Connect к серверам, установленным именно этой версией. Для этих проверок нужны тестовые серверы и устройства.

Обновление VPNAI: проверены команды macOS/Linux (ssh-copy-id), PowerShell, подстановка порта/IP и пути ключа, отклонение некорректных аргументов и выбор локального ключа. Команды не выполнялись на настоящих серверах.

Подготовка ОС: проверены установка отсутствующего Python, пропуск установленного Python, отсутствие установки в проверочном режиме, отказ для неподдерживаемой ОС, команды обновления с сохранением конфигурации и признак необходимости перезагрузки. Все команды выполнялись только через имитации SSH; реальные серверы не обновлялись.

Общее обновление ОС стало опцией Да/Нет, по умолчанию Нет. Проверены оба значения в оркестрации с подменой SSH-серверов: apt-get upgrade выполняется только при Да. Выбор отражается в демонстрации и отчёте, неверные типы параметра отклоняются.


Обновление v0.1.4 (30 октября 2026): регрессии диагностики и старой установки.
Всего 40 тестов: исходные 28 и 12 новых. Дополнительно проверены:
- старая установка с состоянием версии 1 без split-status.json;
- обязательный корректный статус для настоящего раздельного режима;

- отказ восстановления с другим режимом до записи файлов на сервер;

- отказ отдельной службы с указанием этапа/сервера;
- безопасные фиксированные диагностические коды без сырого вывода;
- отказ SSH-авторизации с указанием нужного сервера и без пароля;

без изменения настроек: службы, IPsec, маршруты, TCP OpenVPN с зарубежного

split-status.json с кодом 1. Новая версия не запускалась на этих серверах
автоматически: повторную проверку выполняет владелец после скачивания.
