# Проверки 0.5.0

297 регрессионных тестов на macOS: существующие операции/API/SSH/обновление/DNS, плюс строгая валидация лимитов, отсутствие записи при чтении, подтверждение первой активации, атомарный общий лимит при 16 параллельных подключениях, индивидуальный безлимит и наследование, новый сертификат, точное освобождение одного сеанса, уменьшение без отключения активных, мёртвые процессы и смена NAT, отказ при повреждённой политике, откат ошибки перезапуска и отказ заменять чужие обработчики. Серверные Unix-тесты на Windows пропускаются; клиентские проверки выполняются везде. GitHub Actions повторяет набор на macOS, Linux и Windows.

Дополнительно проверяются web/мобильный интерфейс с подменённым API (чтение, сохранение и отмена лимитов, первый запуск и текущие подключения), APK в ARM64-эмуляторе (SSH/Python/криптография, HTTP/WebView, экспорт и новый сеанс) и автономные desktop-сборки без установленных Python-зависимостей. Состав APK сравнивается с исходниками тега. Подготовка релиза не применяет политику к рабочим VPN-серверам; реальные переподключения устройств после первого включения выполняет пользователь.
