# Проверки 0.4.1

281 регрессионный тест: валидация/API, SSH-доверие, диагностика, пользователи и профили, DNS и откат, чтение и ограниченное обновление без метаданных, автоматическое чтение DNS, жизненный цикл SSH-блокировки. Unix-проверки серверного файлового механизма выполняются на macOS/Linux и пропускаются на Windows; клиентские проверки выполняются на всех desktop-платформах.

Проверки интерфейса используют подменённый API: чтение параметров/DNS/маршрутов, сохранение черновиков, отмена без запуска операции; мобильный интерфейс проверяется по ширине 320/390 пикселей. Готовые desktop-приложения проходят автономный запуск без установленного Python, проверку SSH/криптографии и HTTP API. APK проверяется в ARM64-эмуляторе: Python/SSH/криптография, новые модули обновления и блокировки, HTTP/WebView, экспорт документа и новый сеанс. CI сверяет каждый файл APK с исходниками тега.

В отдельной проверке на RU/EU выполнены шесть временных проверок блокировки: успешная команда, ошибка и отсутствие сигналов при открытом канале на каждом сервере. Проверено освобождение блокировки, удаление тестовых сокетов/файлов; настройки и службы VPN при этих проверках не менялись. Тесты не подтверждают работу на каждом физическом устройстве или в каждой сети.
