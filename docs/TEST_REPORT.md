# Проверки VPNAI v0.1.14

Автоматические тесты проверяют валидацию, режимы маршрутизации, SSH-доверие,
установку с подменой SSH-серверов, сертификаты, удаление, временные ссылки,
память текущего сеанса, очистку данных и формирование архивов.

Регрессия пользователя: восстановление с сохранённым логином `user1` и введённым
в форме `test` должно создавать `test`, сохраняя активного `user1` и его пароль.

В этой работе на серверах выполнялось только чтение. Рабочая конфигурация
и учётные записи не изменялись. Настоящая установка этой версии
проверяется отдельно после её запуска пользователем.

Запуск тестов из папки проекта:

```sh
python3 -m unittest discover -s app/tests -v
```

Интерфейс проверяется в браузере: порядок карточек, подтверждение флажком,
запоминание полей при перезагрузке и очистка при завершении приложения.

Проверки парных архивов: одинаковые имя/ID, совпадение параметров туннеля,
запрет старого формата и смешивания пар, защита от путей вне разрешённых папок,
ссылок и дублирующихся записей, обнаружение повреждения и изменения архива,
подготовка обоих серверов и защитных копий до удаления текущих данных.
Проверены отказ без подтверждения, отсутствие изменений при ошибке второго
архива или второй защитной копии, сохранение путей защитных копий при ошибке.
Настоящее восстановление на VPS в этих тестах не выполнялось.

Интерфейс: центрирование логотипа, ссылки на документацию на всех четырёх
шагах и размещение на узком экране. Полный набор: 163 теста.
Настоящая установка на VPS проверяется отдельно.
