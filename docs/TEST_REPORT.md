# Проверки 0.6.0

308 регрессионных тестов на macOS: существующие операции/API/SSH/обновление/DNS, плюс строгая валидация лимитов, отсутствие записи при чтении, подтверждение первой активации, атомарный общий лимит при 16 параллельных подключениях, индивидуальный безлимит и наследование, новый сертификат, точное освобождение одного сеанса, уменьшение без отключения активных, мёртвые процессы и смена NAT, отказ при повреждённой политике, откат ошибки перезапуска и отказ заменять чужие обработчики. Серверные Unix-тесты на Windows пропускаются; клиентские проверки выполняются везде. GitHub Actions повторяет набор на macOS, Linux и Windows.

Дополнительно проверяются web/мобильный интерфейс с подменённым API (чтение, сохранение и отмена лимитов, первый запуск и текущие подключения), APK в ARM64-эмуляторе (SSH/Python/криптография, HTTP/WebView, экспорт и новый сеанс) и автономные desktop-сборки без установленных Python-зависимостей. Состав APK сравнивается с исходниками тега. Подготовка релиза не применяет политику к рабочим VPN-серверам; реальные переподключения устройств после первого включения выполняет пользователь.

В 0.6.0 дополнительно проверяются кавычки команд client-connect/client-disconnect, полный режим, отказ предварительной проверки без перезапуска служб и реальный парсер OpenVPN в Linux CI. На Mac парсер отдельно проверен на сервере через --show-ciphers, без изменения конфигурации и VPN-служб.

В 0.6.0: повторное использование токена и неизменный срок, независимость UDP/TCP, замена истёкшего и отозванного токена, изменённый файл, запрет неактивного пользователя и символических ссылок, HTTP-выдача точного .ovpn и ответ 410 после истечения через существующий обработчик. Все проверки используют временные каталоги и локальный сервер.
