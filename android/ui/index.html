Шаблон JSON для RU и EU. Можно загрузить .json или .txt с такой же структурой. Заполненный файл содержит пароли.

ИнструкцияНастройка

Два сервера.
Один понятный процесс.

Подготовьте российский и зарубежный серверы — всё остальное установщик сделает по выбранному сценарию.

Ubuntu 24.04/26.04 или Debian 12/13, root-доступ. При установке Python 3 устанавливается автоматически, если отсутствует, общее обновление пакетов ОС выполняется только по вашему выбору, без перезагрузки. Нужны публичные IPv4, назначенные интерфейсам, и свободный выбранный порт OpenVPN UDP/TCP (по умолчанию 1194), 80/443 TCP и 500/4500 UDP. TCP 80 на российском сервере оставьте доступным для автоматического продления HTTPS; служебный канал к API работает через защищённый туннель.

SSH-ключи будут получены автоматически при запуске операции. При первом подключении подтвердите доверие серверам один раз; изменение сохранённого ключа остановит подключение.

Вы запускаете исходники без SSH-зависимостей. В готовой сборке они уже включены. Для исходников закройте приложение и запустите из папки app: setup-ssh-windows.bat (Windows), setup-ssh-macos.command (macOS) или setup-ssh-linux.sh (Linux). Затем запустите приложение снова.
