ШАГ 01 / 04

Два сервера.
Один понятный процесс.

Подготовьте российский и зарубежный серверы — всё остальное установщик сделает по выбранному сценарию.

Попробовать без серверов

Весь процесс на примере. Ни одного SSH-подключения.

Ubuntu 24.04/26.04 или Debian 12/13, root-доступ. При установке Python 3 устанавливается автоматически, если отсутствует, общее обновление пакетов ОС выполняется только по вашему выбору, без перезагрузки. Нужны публичные IPv4, назначенные интерфейсам, и свободные порты 1194 UDP/TCP, 80/443 TCP, 500/4500 UDP.
Отпечатки ещё не получены.
SSH-компонент пока не установлен. Для реальных серверов закройте приложение и запустите из папки app: setup-ssh-windows.bat (Windows), setup-ssh-macos.command (macOS) или setup-ssh-linux.sh (Linux). Затем запустите приложение снова. Демонстрация работает без него.
Начните с демонстрации — серверы не нужны.
