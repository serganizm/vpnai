VPNAI — самостоятельный установщик VPN

Python и SSH-компонент уже включены в готовые сборки.
Устанавливать Python, Paramiko, pip или запускать setup-ssh не нужно.

1. Скачайте файл для своей ОС в Assets релиза v0.1.12:
   Windows 10/11 x64: VPNAI-v0.1.12-windows-x64.exe
   macOS 15+ Apple Silicon: VPNAI-v0.1.12-macos-arm64.zip
   Linux x64 (glibc 2.35+): VPNAI-v0.1.12-linux-x64.tar.gz
2. На Windows запустите .exe. На macOS/Linux распакуйте архив и запустите
   единственный исполняемый файл внутри. Для Linux при необходимости
   разрешите запуск файла в его свойствах.
3. Автоматически откроется браузер с локальным интерфейсом.
4. Для пробы без серверов оставьте демонстрацию включённой.
5. Для работы с VPS введите данные серверов и запустите операцию.
   SSH-отпечатки будут получены автоматически; для новых серверов подтвердите доверие.
6. Если VPN уже установлен, сначала выберите «Проверить VPN».

Во время работы не закрывайте окно приложения. Для выхода нажмите «Закрыть VPNAI» в приложении либо Ctrl+C
в его окне. Закрытие вкладки браузера само по себе не завершает программу.

Библиотеки распаковываются из самого файла во временный каталог во время
работы. Они не скачиваются и не устанавливаются в системный Python.
После штатного завершения временный каталог удаляется.
Для подключения к VPS и установки VPN интернет необходим.

Самостоятельные сборки пока не подписаны издательским сертификатом Windows
или Apple Developer ID; ОС может запросить разрешение на запуск.

Инструкция доступна по ссылке «Инструкция» в приложении; подробные сведения
по ссылке «Настройка». Публичные SSH-отпечатки сохраняются в
~/.vpnai/ssh-hosts.json (Windows: %USERPROFILE%\.vpnai\ssh-hosts.json).
Пароли и приватные ключи в эту базу не записываются.

После установки управление пользователями и маршрутизацией:
  ssh root@IP_РОССИЙСКОГО_СЕРВЕРА
  cd /root
  ./menu.sh
Для нестандартного SSH-порта: ssh -p ПОРТ root@IP_РОССИЙСКОГО_СЕРВЕРА

Архив VPNAI-source-v0.1.12.zip — исходники для разработчиков.
Только для него нужны отдельный Python и setup-ssh-скрипт.
В исходниках подробные инструкции находятся в docs/readme.md.

Для удаления прежней установки выберите «Удалить установку» и введите
УДАЛИТЬ. Повторный запуск продолжит частично завершённое удаление.
На обоих серверах перед удалением сохраняется /root/ovpn-backup-*.tar.gz.

После сбоя HTTPS в прежней версии выберите восстановление установки.
Автопродление HTTPS включится после установки новой версии на серверы:
проверка каждый час, доступ к Let’s Encrypt через NL, ключ остаётся на RU.
Не закрывайте входящий TCP 80 на российском сервере.
