VPNAI 0.3.1 — Панель управления

Готовые приложения: Android ARM64 (7+), macOS Apple Silicon, Linux x64, Windows x64. Python и SSH входят в автономные приложения.

Откройте приложение, укажите серверы в «Подключении», затем выберите «Установка» или «Управление». JSON/TXT с заполненными SSH-данными можно загрузить через «Файл».

Чтобы остановить desktop-приложение, завершите его окно запуска (Ctrl+C). Во время операций оставляйте его работающим. При завершении процесса данные сеанса теряются.

Подробности, ограничения и сборка Android: docs/RELEASE_NOTES.md, docs/ANDROID.md, docs/SETUP.md.
