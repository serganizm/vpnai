VPNAI 0.3.2 — Панель управления

Запустите готовую сборку своей ОС. Desktop открывает браузер, Android — встроенную панель. Python и SSH входят в приложение.

Подключение: SSH-данные RU/EU, пароль root или ключ; импорт JSON/TXT через меню «Файл». Затем Установка (настройки VPN, маршруты, запуск) либо Управление (пользователи, конфигурации, маршрутизация).

Проверки выбираются в Установка → Настройки VPN. Они не меняют настройки серверов, не считают существующую VPN-подсеть конфликтом новой установки и не требуют state.json. Неизвестные пункты явно отмечены; HTTPS, сквозные выходы и клиент OpenVPN не проверяются.

Для диагностики достаточно заполнить форму; предварительный успех административной кнопки «Подключиться» не обязателен. Отсутствие файлов установщика не позволяет автоматически обновлять/удалять действующий VPN.

Кнопки закрытия нет. Desktop: после окончания операции Ctrl+C в окне запуска. Закрытие вкладки и сворачивание Android не останавливают backend. Данные сеанса теряются при завершении процесса.
