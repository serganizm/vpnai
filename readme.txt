VPNAI — локальный установщик OpenVPN

Для запуска нужен Python 3.9 или новее: https://www.python.org/downloads/

1. Полностью распакуйте VPNAI-vX.Y.Z.zip.
2. Запустите файл для вашей системы:
   macOS:   macos.command (двойной щелчок).
   Linux:   bash linux.sh из папки VPNAI.
   Windows: windows.bat (двойной щелчок).
3. Приложение автоматически откроется в браузере.
4. Для пробы без серверов оставьте включённой демонстрацию.

Для установки VPN на настоящих серверах нужен SSH-компонент (Paramiko).
Установите его на своём компьютере один раз для этой папки приложения:
1. Закройте приложение и окно его запуска.
2. Откройте папку app и запустите файл для вашей системы:
   Windows: setup-ssh-windows.bat (двойной щелчок).
   macOS:   setup-ssh-macos.command (двойной щелчок).
   Linux:   bash setup-ssh-linux.sh из папки app.
3. Дождитесь сообщения «Готово». Нужен интернет для скачивания библиотеки.
4. Снова запустите windows.bat, macos.command или linux.sh из основной папки.
Если появилась ошибка, сохраните текст из окна установки.
Для демонстрации SSH-компонент не требуется.

На серверах Python 3 проверяется и устанавливается автоматически, если его нет.
Обновление пакетов ОС выбирается на шаге «Настройки VPN»: Да или Нет.
По умолчанию выбрано Нет. Python и необходимые VPN-пакеты устанавливаются автоматически.
Автоматическая перезагрузка не выполняется.

Во время установки не закрывайте окно запуска приложения.
Если macos.command не открывается двойным щелчком, выполните
bash macos.command в Терминале из папки VPNAI.

Настройка пользователей и маршрутизации после установки:
1. Подключитесь по SSH к российскому серверу:
   ssh root@IP_РОССИЙСКОГО_СЕРВЕРА
   Если SSH-порт отличается от 22:
   ssh -p ПОРТ root@IP_РОССИЙСКОГО_СЕРВЕРА
2. Войдя под root, запустите меню:
   cd /root
   ./menu.sh
3. В меню выберите «Пользователи» или «Маршрутизация».

Подробная инструкция находится в docs/readme.md.
