VPNAI — установка OpenVPN на два сервера

1. Запустите готовое приложение для своей ОС.
   macOS Apple Silicon / Linux: распакуйте архив и откройте исполняемый файл.
   Windows x64: откройте .exe.
2. Введите IP, SSH-порт и данные root российского и зарубежного серверов.
3. Выберите действие, маршрутизацию, способ входа и пользователя для создания.
4. При необходимости заполните списки маршрутов и запустите операцию.
5. Для удаления, установки заново или восстановления из архива прочитайте описание и отметьте
   «Я подтверждаю выполнение выбранного действия».

IP, пароли, ключи и SSH-доверие хранятся только в памяти текущего запуска.
Кнопка «Новая операция» сохраняет введённые данные. Перезагрузка вкладки
также восстанавливает их, пока приложение работает. После завершения
приложения данные сеанса очищаются и при следующем запуске вводятся заново.
Закрытие одной вкладки не завершает приложение. Используйте «Закрыть VPNAI»
или Ctrl+C в окне приложения; активная операция сначала должна завершиться.

Управление пользователями и маршрутами после установки:
  ssh root@IP_РОССИЙСКОГО_СЕРВЕРА
  cd /root
  ./menu.sh
Для своего SSH-порта: ssh -p ПОРТ root@IP_РОССИЙСКОГО_СЕРВЕРА

Архив пользователя: openvpn-ЛОГИН.zip. Все пользователи: openvpn-all.zip.
Внутри — UDP/TCP-профили и файл доступа. Ссылка действует 10 минут.
Автоматическое продление HTTPS проверяется каждый час. TCP 80 на российском
сервере должен быть доступен из интернета.

Подробная инструкция: docs/readme.md. Настройка: docs/SETUP.md.
Ссылки «Инструкция» и «Настройка» — на одной строке с номером шага, у правого края. Ссылка GitHub находится под названием приложения.
Исходники запускаются через macos.command, linux.sh или windows.bat;
для исходников нужны Python 3.9+ и зависимости app/requirements.txt.
Готовая сборка содержит всё необходимое для локального запуска.
Для исходников один раз выполните на локальном компьютере файл из app:
setup-ssh-macos.command / setup-ssh-linux.sh / setup-ssh-windows.bat
для своей ОС, затем используйте соответствующий запускной файл в корне.
Подготовка создаёт app/.venv. На VPS запускать эти файлы не нужно.

Восстановление из копии: «Обновить/Восстановить» → список архивов → выбрать копию на
российском сервере. Соответствующая зарубежная копия выбирается автоматически.
Работает только новый формат: имена и ID снимка на обоих серверах одинаковые.
Новые копии создаются перед удалением, установкой заново и восстановлением.

Закрыть VPNAI: светло-красная кнопка слева внизу любого шага.
Назад и продолжение — справа. Инструкция и Настройка — у правого края
на уровне номера шага.


Обновление действующей конфигурации: сначала загрузите текущие настройки и списки
с сервера, затем измените их в форме. Применяются маршрутизация, способ входа, порт
и ручные списки; обновляются серверные файлы и меню. Пользователи и сертификаты
сохраняются; новый пользователь создаётся только если нет неудалённых пользователей.
Перед записью создаются парные защитные архивы; изменение конфигурации после
загрузки останавливает запуск до записи. Службы перезапускаются: скачайте новые
профили и переподключите устройства. Существующие действующие пароли сохраняются.
При включении парольного входа для пользователей без сохранённого действующего
пароля создаются новые пароли; имена указаны в отчёте, пароли — в архиве профилей.
При ошибке обновления используйте защитную пару архивов; автоматическое удаление
компонентов в этом случае не выполняется.
