# VPNAI — Панель управления

Локальное приложение для установки и управления OpenVPN на паре серверов RU/EU. Браузерный интерфейс на Windows, macOS и Linux; отдельная APK для Android.

## Скачать 0.6.0

[Релиз v0.6.0](https://github.com/serganizm/vpnai/releases/tag/v0.6.0) содержит Android ARM64 (7+), macOS Apple Silicon, Linux x64, Windows x64, исходники и общий архив четырёх приложений. Контрольные суммы — SHA256SUMS.txt. Python и SSH включены в готовые приложения. Intel Mac и Android x86 в эти сборки не входят.

## DNS для VPN-клиентов

В «Управление → Маршрутизация» можно выбрать Google, Cloudflare или свои публичные IPv4 DNS. Применение общее для UDP/TCP и требует переподключить устройства. Путь запросов: устройство → RU → GRE/IPsec → EU → DNS. При установке DNS включается отдельно. [Инструкция по DNS](docs/DNS.md).

## Начало работы

1. Запустите готовое приложение. Desktop открывает локальный браузер; APK — встроенный интерфейс.
2. В разделе «Подключение» введите IPv4, SSH-порт и пароль root либо ключ обоих серверов. Сверьте SSH-отпечатки. Меню «Файл» позволяет скачать пустой JSON-шаблон и загрузить заполненный JSON/TXT.
3. Выберите «Установка» (настройки VPN, маршруты, запуск) либо «Управление» (пользователи, конфигурации, маршрутизация). В desktop основные разделы наверху, пункты выбранного раздела слева; на телефоне пункты раздела внизу.
4. Для диагностики выберите в «Установке → Настройки VPN» действие «Проверить серверы» или «Проверить VPN», затем перейдите к запуску. Запуск проверки не устанавливает и не восстанавливает VPN.

Кнопки закрытия в интерфейсе нет. Закрытие вкладки или сворачивание Android не завершает backend. Для остановки desktop дождитесь окончания операции и нажмите Ctrl+C в окне запуска. На Android процесс и уведомление могут оставаться активными; системная остановка приложения очищает сеанс. Во время изменений держите приложение открытым.

## Проверки 0.6.0

«Проверить серверы» читает SSH, ОС, инвентаризацию и доступные режимы; существующая VPN-подсеть не считается конфликтом новой установки. «Проверить VPN» дополнительно читает конфигурации OpenVPN, службы и порты, пересылку IPv4, маршруты VPN, GRE к выбранному партнёру и IPsec SA. Отсутствие state.json/owned.json — предупреждение, а не доказательство отсутствия VPN. Недоступные проверки отмечаются как неполные; неудачный ping сам по себе не объявляет VPN неработающим.

Проверки не создают серверные файлы, интерфейсы или сетевые пространства и не перезапускают службы. Они не проверяют HTTPS, сквозные выходы клиентского трафика и OpenVPN-клиент на устройстве. Более глубокие тесты после установки остаются частью установочной операции.

## Ограничения

Форма «Подключиться» по-прежнему использует административные команды установленного VPNAI. Её отказ на чистом/старом сервере не равнозначен отказу SSH: для таких серверов можно заполнить форму и перейти напрямую к проверке в «Установке»; SSH-доверие запрашивается при запуске операции. Диагностика старых установок не даёт права автоматически обновлять или удалять их: для изменения компонентов нужны отдельные проверки состояния и принадлежности.

Данные доступа и доверие живут в памяти текущего запуска. Заполненный JSON/TXT и скачанные профили содержат секреты и остаются там, где их сохранил пользователь. macOS-сборка не нотарифицирована Apple; APK подписана прежним отладочным ключом и устанавливается поверх предыдущих APK этого проекта с той же подписью.
