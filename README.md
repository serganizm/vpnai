# VPNAI

Локальное веб-приложение для установки OpenVPN на двух серверах: российском и зарубежном. Запускается на macOS, Linux и Windows, открывается в браузере и управляет установкой по SSH.

**Можно попробовать без серверов:** демонстрационный режим включён по умолчанию и не создаёт SSH-соединений.

## Скачать готовый архив

Откройте [Releases](https://github.com/serganizm/vpnai/releases) и скачайте **VPNAI-vX.Y.Z.zip** из Assets. Рядом публикуется `SHA256SUMS.txt` для проверки целостности. Для приватного репозитория требуется вход в GitHub с доступом к нему.

Архив содержит приложение, файлы запуска и папку `docs` со всей подробной документацией. Файлы Git/GitHub и README страницы репозитория в него не включаются. Сборка выпускается автоматически после создания тега вида `v0.1.0`: сначала выполняются тесты и проверка контрольных сумм.

## Быстрый запуск

1. Скачайте **VPNAI-vX.Y.Z.zip** через **Releases → Assets** и полностью распакуйте архив либо клонируйте его:

```bash
git clone https://github.com/serganizm/vpnai.git
cd vpnai
```

2. Установите Python **3.9 или новее** с [python.org](https://www.python.org/downloads/), если его нет. На Windows включите **Add Python to PATH**.
3. Запустите файл для вашей системы:

| Система | Запуск из корня проекта |
|---|---|
| macOS | Двойной щелчок по `macos.command` или `bash macos.command` |
| Linux | `bash linux.sh` |
| Windows | Двойной щелчок по `windows.bat` |

Браузер откроется автоматически. Для демонстрации SSH-зависимости не нужны. Во время операции оставляйте окно запуска открытым.

## Возможности

- Проверка серверов и обнаружение сохранённой установки.
- Установка, восстановление, проверка VPN, установка заново и удаление компонентов этой установки.
- OpenVPN UDP и TCP; порт выбирается в форме.
- GRE-туннель, защищённый IPsec, между серверами.
- Три режима IPv4-маршрутизации.
- Индивидуальные сертификаты с логином/паролем либо вход только по сертификату.
- Отдельные ручные списки RU и RU-EU; изначально пустые.
- SSH по паролю, вставленному приватному ключу или локальному файлу ключа.
- Генерация команды копирования публичного SSH-ключа для macOS/Linux/PowerShell с выбранными IP и портом.
- Автоматическая установка Python 3 на серверах при его отсутствии.
- Опциональное общее обновление пакетов ОС: **Да/Нет**, по умолчанию **Нет**.
- Прогресс операции, остановка между этапами, отчёт и скачивание профилей на локальный компьютер.

## Как проходит трафик

В режиме раздельных маршрутов:

```text
Устройство
├── IPList или ручной RU-EU → российский сервер → GRE/IPsec → зарубежный → интернет
├── Ручной RU              → российский сервер → интернет
└── Остальные IPv4         → напрямую через обычное подключение устройства
```

RU имеет приоритет над обоими списками RU-EU. IPList загружается с [iplist.opencck.org](https://iplist.opencck.org/ru/) отдельно от ручных списков. После изменения маршрутов клиенту нужно переподключиться; заменять стандартный `.ovpn` не требуется.

Также доступны: весь IPv4-трафик через VPN с выбором выхода по спискам и весь внешний IPv4-трафик через зарубежный сервер. **IPv6 остаётся прямым**, DNS-настройки устройства не заменяются.

## Настройка настоящих серверов

Подробные шаги: **[гайд по настройке](docs/SETUP.md)**.

Потребуются Ubuntu 24.04/26.04 либо Debian 12/13, два разных публичных IPv4 на интерфейсах, root-доступ и свободные порты. При первом запуске для реальных серверов установите SSH-компонент скриптом `app/setup-ssh-<ОС>.*`. SSH-ключи получаются автоматически при запуске операции. Для нового сервера нужно один раз подтвердить доверие; последующие подключения сверяются с локально сохранённым ключом.

После установки управление пользователями и маршрутами выполняется на российском сервере:

```bash
ssh root@IP_РОССИЙСКОГО_СЕРВЕРА
cd /root
./menu.sh
```

## Проверки

Из корня проекта:

```bash
python3 -m unittest discover -s app/tests -v
```

На Windows:

```powershell
py -3 -m unittest discover -s app/tests -v
```

На момент публикации прошли **58 тестов**: валидация, шесть сочетаний режимов, API, имитация SSH-установки, команды ключей, подготовка Python и опциональные обновления. Демонстрация проверена в браузере.

Полная SSH-установка именно этой веб-версии на чистой паре VPS ещё не проверена. Запуск на физических Windows/Linux и подключение клиента к серверам, установленным этой версией, требуют отдельной проверки. Для первого развёртывания используйте тестовую пару серверов.

## Данные и доступ

Приложение слушает только `127.0.0.1` и использует временный токен доступа. SSH-пароли и введённые ключи не записываются в локальные файлы или отчёт. Локальный приватный SSH-ключ читается только для авторизации и не копируется на сервер.

VPN-ключи, профили и сгенерированные пароли пользователей сохраняются в закрытых файлах на российском сервере. Архив профилей в памяти приложения доступен 10 минут. В режиме входа только по сертификату копия `.ovpn` даёт доступ к VPN.
