# VPNAI

Локальное веб-приложение для установки OpenVPN UDP/TCP на два сервера:
российский принимает подключения, зарубежный обеспечивает выход выбранного
трафика через защищённый GRE/IPsec-туннель. После установки управление
пользователями и маршрутами доступно через `/root/menu.sh` на российском сервере.

## Скачать и запустить

[Релиз v0.1.14](https://github.com/serganizm/vpnai/releases/tag/v0.1.14)

| Компьютер | Файл в разделе Assets |
|---|---|
| Windows 10/11 x64 | `VPNAI-v0.1.14-windows-x64.exe` |
| Mac с Apple Silicon | `VPNAI-v0.1.14-macos-arm64.zip` |
| Linux x64 | `VPNAI-v0.1.14-linux-x64.tar.gz` |
| Исходники | `VPNAI-source-v0.1.14.zip` |

На macOS и Linux распакуйте архив и запустите исполняемый файл. На Windows
откройте `.exe`. Python, SSH-компонент и интерфейс уже включены: отдельная
установка локальных зависимостей не требуется. Mac с Intel не поддерживается.
Для сверки файлов опубликован `SHA256SUMS.txt`.

Для обычного запуска выбирайте готовый файл своей ОС из Assets.
Автоматические архивы GitHub «Source code» содержат репозиторий для разработки;
подготовленный архив исходников `VPNAI-source-v0.1.14.zip` содержит приложение,
инструкции и запускные файлы без файлов Git и системного мусора.

## Как работает

1. Введите IP, SSH-порт и пароль root либо SSH-ключ обоих серверов.
2. Выберите действие, маршрутизацию, авторизацию и логин создаваемого пользователя.
3. При необходимости заполните ручные IPv4/CIDR-списки. Изначально они пусты.
4. Проверьте итог и запустите операцию. SSH-отпечатки получаются автоматически;
   при первом соединении подтвердите доверие серверам.
5. После установки скачайте профили и импортируйте UDP или TCP в OpenVPN Connect.

Нужны Ubuntu 24.04/26.04 либо Debian 12/13, root-доступ и два публичных IPv4,
назначенных интерфейсам напрямую. Python 3 и необходимые VPN-пакеты на серверах
устанавливаются автоматически. Общее обновление пакетов выбирается отдельно.

Действия: установка, установка заново, восстановление, проверка VPN,
проверка серверов, удаление. Перед удалением, установкой заново и восстановлением
из архива требуется подтверждение флажком с описанием последствий.

Маршрутизация: раздельная по спискам, весь IPv4 через VPN с двумя выходами
либо весь IPv4 через зарубежный сервер. RU имеет приоритет над RU-EU и IPList.
DNS и IPv6 требуют отдельной проверки на устройстве.

Восстановление поддерживает текущую конфигурацию либо парный архив нового
формата: архив выбирается на российском сервере, соответствующая зарубежная
копия определяется автоматически. Имена и ID снимка одинаковые на обоих
серверах. Старый формат архивов не поддерживается.

IP, пароли, ключи и SSH-доверие доступны только в памяти текущего запуска.
«Новая операция» и обновление вкладки сохраняют их до выхода из приложения.
Закрытие вкладки само по себе не завершает процесс: используйте «Закрыть VPNAI»
или Ctrl+C в окне запуска. Вручную скачанные отчёты содержат адреса серверов,
а архивы профилей — данные доступа; эти файлы остаются там, куда вы их сохранили.

## Запуск исходников

Исходники: `app/`, `docs/`, `readme.txt`, `macos.command`, `linux.sh`, `windows.bat`.
Нужен Python 3.9+. Один раз подготовьте зависимости **на локальном компьютере**:

- macOS: `app/setup-ssh-macos.command`, затем `macos.command`.
- Linux: `sh app/setup-ssh-linux.sh`, затем `sh linux.sh`.
- Windows: `app/setup-ssh-windows.bat`, затем `windows.bat`.

Подготовка создаёт `app/.venv` и устанавливает зависимости из
`app/requirements.txt` в неё. Для готовых исполняемых сборок этот шаг не нужен.

## Проверки

```sh
python3 -m unittest discover -s app/tests -v
```

Релиз собирается в GitHub Actions отдельно для трёх ОС. Публикация выполняется
после успешных тестов и проверки готового приложения на каждой платформе.
Проверки с подменой SSH и изолированными каталогами не заменяют установку на
реальных VPS и проверку OpenVPN Connect на нужном устройстве.
