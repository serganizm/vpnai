# VPNAI 0.3.1

## Интерфейс

- Три основных раздела: «Подключение», «Установка», «Управление». Данные серверов вводятся в одном месте и подставляются в установку.
- Веб-версия: основные вкладки в верхней строке, слева — пункты выбранного раздела. При подключении один пункт, при установке и управлении — по три.
- Отдельный интерфейс для телефонов: карточки серверов и пользователей, нижняя навигация, адаптация к узкому экрану.
- Активная вкладка выделяется фиолетовой заливкой. Обновлены шрифты, отступы, логотип и подпись «Панель управления».
- Общая индикация подключения, меню «Файл» с JSON-шаблоном и импортом JSON/TXT.
- «Назад» имеет одинаковую ширину на всех шагах, основная кнопка занимает остальное место. Стрелки и кнопка «Закрыть VPNAI» убраны.

## Файлы

- Android 7+ ARM64: APK с встроенным Python/SSH.
- macOS Apple Silicon: ZIP с автономным приложением.
- Linux x64: TAR.GZ с автономным приложением.
- Windows x64: автономный EXE.
- Исходники desktop и Android; общий ZIP со всеми четырьмя готовыми приложениями; SHA256SUMS.txt.

## Проверки и ограничения

Desktop-сборки проходят регрессионные тесты и автономную проверку на своих ОС. Android проверен в Android 15 ARM64-эмуляторе. Это не проверка совместимости со всеми физическими устройствами.

Общая форма подключения использует прежнюю серверную проверку установленного VPNAI. Сценарий предварительного подключения к чистым серверам пока не подтверждён. Серверные операции и модель отдельных backend-сеансов не переработаны в этом интерфейсном релизе. Установка, обновление и другие действия запускаются пользователем; при сборке релиза VPS не изменяются.

macOS-приложение не нотарифицировано Apple; Android APK подписана отладочным ключом. Для запуска desktop-сборок устанавливать Python не нужно.
